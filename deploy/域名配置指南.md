## ⚙️ 域名配置步骤

### 如果选择IP访问（无需域名）

1. **部署完成后直接访问**：
   ```
   http://您的服务器IP地址
   ```

2. **获取服务器IP**：
   ```bash
   # 在服务器上执行
   curl ifconfig.me
   ```

### 如果购买了域名

#### 步骤1：购买域名
- 选择合适的域名（建议包含"mentor"、"academy"等关键词）
- 推荐域名示例：
  - `mentor-academy.com`
  - `tutor-college.com`
  - `academy-mentor.cn`

#### 步骤2：域名解析设置
在域名管理后台添加A记录：
```
类型: A
主机记录: @
记录值: 您的服务器IP地址
TTL: 600

类型: A  
主机记录: www
记录值: 您的服务器IP地址
TTL: 600
```

#### 步骤3：修改Nginx配置
```bash
# 在服务器上执行
cp /root/deploy/nginx-with-domain.conf /etc/nginx/sites-available/mentor-academy

# 修改域名
sed -i 's/your-domain.com/实际域名/g' /etc/nginx/sites-available/mentor-academy

# 重新加载配置
nginx -t && systemctl reload nginx
```

#### 步骤4：配置SSL证书（推荐）
```bash
# 安装 Certbot
apt install certbot python3-certbot-nginx

# 获取免费SSL证书
certbot --nginx -d 您的域名.com -d www.您的域名.com

# 设置自动续期
crontab -e
# 添加以下行：
0 12 * * * /usr/bin/certbot renew --quiet
```

## 🔒 安全配置

### 防火墙设置
```bash
# 开放必要端口
ufw allow ssh
ufw allow http
ufw allow https
ufw enable
```

### 域名安全
1. **启用域名锁定**：防止域名被恶意转移
2. **设置域名隐私保护**：隐藏个人信息
3. **定期检查域名状态**：确保域名正常解析

## 📊 访问测试

### 测试步骤
1. **DNS解析测试**：
   ```bash
   nslookup 您的域名.com
   ```

2. **网站访问测试**：
   - 浏览器访问：`http://您的域名.com`
   - 检查所有功能是否正常

3. **SSL证书测试**（如果配置了HTTPS）：
   - 访问：`https://您的域名.com`
   - 检查证书是否有效

## ❓ 常见问题

**Q: 域名解析需要多长时间生效？**
A: 通常5-30分钟，最长可能需要24小时。

**Q: 可以先用IP访问，后续再配置域名吗？**
A: 可以，随时可以添加域名配置。

**Q: SSL证书是必需的吗？**
A: 不是必需的，但强烈推荐，可以提高安全性和SEO排名。

**Q: 如果域名忘记续费会怎样？**
A: 域名会过期，网站无法访问，建议设置自动续费。
