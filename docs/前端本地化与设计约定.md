# 前端本地化与设计约定

## 目标

本项目面向中文用户，前端界面默认使用简体中文表达，确保日期、时间、分页、弹窗、表单提示等交互文案符合中文用户习惯。

## 当前约定

1. 所有新页面、新组件默认使用简体中文。
2. 日历、日期选择器、时间选择器、分页器等第三方组件优先启用中文语言包。
3. 页面中的按钮、提示语、空状态、校验文案、表格操作文案统一使用中文。
4. 若存在英文专有名词，优先采用“中文为主，英文为辅”的展示方式。
5. 后续新增设计稿、重构页面、扩展后台时，默认沿用本约定，除非有明确的双语或英文需求。

## 实施要求

1. Vue + Element Plus 入口层统一配置中文 locale，避免局部组件遗漏。
2. 引入新组件库或新插件时，优先检查其本地化能力，并默认切换为中文。
3. 分页、日期范围、时间格式、弹窗按钮等高频交互必须在联调时确认中文展示是否正确。
4. 如需例外展示英文，必须基于明确业务需求单独说明。

## 后续设计原则

1. 所有后续前端设计改版默认遵循“中文优先、表达直接、易读易懂”的原则。
2. 对中文用户高频使用的页面，尽量减少纯英文标签、纯英文导航和英文状态词。
3. 涉及报名、管理、审批、统计等核心流程时，优先保证中文信息层级清晰，再考虑视觉装饰。
