# 管理员仪表盘图表升级共识 (AdminDashboardCharts)

## 需求描述与验收标准

- 需求：在管理员仪表盘新增数据分析图表，至少包含：
  - 折线图：支持周期切换 90 天、30 天、7 天、一天（24 小时）
  - 柱状图：Top10 统计（类别/导师可切换）
  - 热力图：周-时分布（按小时与星期）
  - 可扩展图：容量利用率散点图（可视化容量与已报名关系）
- 数据来源：复用现有管理端接口 `/api/admin/activities` 与 `/api/admin/activities/summary`
- 聚合方式：前端聚合，基于活动 `startAt` 与 `registeredCount`；后续可引入后端聚合接口以提升精度与性能
- 技术栈：Vue 3 + Element Plus + Apache ECharts 5
- 验收标准：
  1. 管理员仪表盘显示 4 个图表卡片；
  2. 周期、维度、指标切换控件工作正常；
  3. 数据加载与图表渲染无控制台报错；
  4. 页面在桌面与移动端具备基本响应式；
  5. 本地预览与线上部署后可正常访问。

## 技术实现方案与约束

- 前端：新增 `AdminCharts.vue`，静态导入 ECharts 并初始化 4 个图表实例；使用 Element Plus 控件进行交互
- 数据：调用 `/admin/activities` 获取活动基础信息与 `startAt`、`limit`；调用 `/admin/activities/summary` 获取 `registeredCount`
- 聚合：
  - 折线图：周期为天（90/30/7）按日期聚合；一天模式按小时聚合
  - 柱状图：类别/导师维度，取 Top10 并按指标排序
  - 热力图：周-时二维网格，值为报名人次或活动场次
  - 散点图：x=容量限制、y=已报名、气泡大小按填充率映射
- 约束：不修改数据库与后端模型；如需更高精度（按报名 `createdAt` 聚合），后续新增管理端聚合接口

## 任务边界

- 本次交付范围：前端页面与图表实现、控件交互、数据聚合、预览与部署
- 不包含：后端新建聚合 API（标记为后续可选项），复杂过滤器（类别/导师联动筛选）

## 不确定性与澄清

- 报名趋势的统计口径：当前以活动 `startAt` 近似统计；如需改为报名 `createdAt`，需后端聚合接口支持
- 图表主题与配色：采用默认主题，可在后续优化阶段统一视觉风格
- 性能：静态导入 ECharts，后续可按需引入实现更细粒度模块化

## 最终共识

按上述方案交付 4 个图表与交互控件，确保与现有项目兼容并可在线部署；后续根据需要补充后端聚合接口与更多图表类型。
