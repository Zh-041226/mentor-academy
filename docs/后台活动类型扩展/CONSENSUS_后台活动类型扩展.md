# 后台活动类型扩展共识

## 需求描述

- 后台“新建活动/编辑活动”的活动类型不能只停留在固定预设值。
- 需要同时支持：预设类型、历史活动中已出现的类型、管理员直接输入新类型。
- 目标是让活动类型随着业务增长自然扩展，而不是每新增一次类型都改代码。

## 范围

- 前端：`frontend/src/views/admin/AdminActivities.vue`
- 后端：`backend/src/server.js`
- 本轮不改数据库结构，不新增独立“类型管理表”。

## 实现约束

- 保留预设类型优先展示。
- 历史类型来源于已存在活动数据中的 `category` 字段。
- 新输入的类型仅在活动保存成功后，才会进入可选列表。
- 不影响前台活动展示、类型标签映射和筛选逻辑。

## 验收标准

- 新建活动时，下拉中能看到预设类型与历史类型。
- 管理员可以直接输入新的活动类型并成功保存。
- 编辑已有活动时，历史自定义类型能够直接回填并复用。
- 保存成功后，新类型在后续新建/编辑中可再次选择。
- 前端诊断通过，前端构建通过，后端语法检查通过。
