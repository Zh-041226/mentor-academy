# 导师进书院活动系统 — 共识文档

## 概述
- 目标：搭建面向书院的导师活动管理与学生参与平台，覆盖活动发布、报名管理、活动执行、反馈收集与数据分析的完整闭环。
- 受众：学生（普通用户）、书院老师/负责人（管理员）、导师。
- 范围：Web 端为主（PC 优化，移动端适配），后续可扩展移动小程序或 App。

## 核心业务流程
管理员发布活动 → 学生查看/报名 → 管理员管理报名名单 → 活动举行 → 学生反馈 → 管理员归档/分析。

## 模块与功能共识
### 一、普通用户模块（学生）
- 注册/登录：支持学号注册登录；如书院已有统一认证，支持单点登录（SSO）。
- 个人信息管理：姓名、年级、专业、联系方式等的查看与编辑。
- 活动广场：
  - 活动列表：卡片/列表展示已发布活动。
  - 筛选与搜索：导师、活动类型（讲座/工作坊/茶话会/读书会/一对一）、时间/状态（即将开始/报名中/已结束）、关键字（标题/导师/简介）。
  - 活动详情：标题、封面图、导师介绍（照片、职称、方向、简介）、时间地点、类型、人数限制、当前报名人数、详细介绍。
  - 报名/取消报名：报名窗口内可操作，名额与重复报名规则校验。
- 我的活动：
  - 我报名的、待参加提醒、已参加/历史记录。
  - 我的收藏：收藏但暂未报名的活动。
- 导师风采：导师名录与详情页（完整介绍、过往活动、学术成果、学生评价）。
- 反馈与评价：活动后推送问卷，已参加活动可星级评分与文字评价（管理员审核后展示）。

### 二、管理员模块（老师/助管）
- 仪表盘：近期活动数、总报名人次、活跃用户数、活动满意度平均分；待办提醒（待审核报名、待发布活动）。
- 活动管理：创建/编辑活动（完整信息录入）、状态管理（草稿/已发布/报名中/已截止/已结束/已取消）、复制活动。
- 报名管理：报名名单查看与导出 Excel；报名审核（可选）；手动增删学员。
- 导师管理：导师信息库的增删改查；活动关联导师。
- 用户管理：学生信息查看；启用/禁用账号。
- 反馈与数据分析：查看反馈与评价；多维统计（活动热度、导师人气、学生参与度），生成报告。
- 系统设置：公告管理；权限管理（超级管理员、运营管理员等）。

## 技术实现方案（与版本兼容的建议）
- 前端：Vue 3 + Vite（路由：Vue Router，状态：Pinia，UI：Element Plus）。
- 后端：Node.js（优先）
  - 框架：NestJS 或 Express（优先选择 NestJS 以保证模块化与可维护性）。
  - ORM：Prisma（MySQL），或 TypeORM。
  - 认证：JWT（可与 SSO/OAuth2 对接）。
- 数据库：MySQL 8。
- 环境与工具：Node.js ≥ 18 LTS；Vite 5；Pinia 2；Element Plus 2；Prisma 5。
- 部署：先从单体应用开始（前后端分离），后续可容器化（Docker）与 CI/CD。

## 数据模型（概要）
- User（学生）：id、学号/邮箱、姓名、年级、专业、联系方式、状态、注册时间、角色。
- Mentor（导师）：id、姓名、照片、职称、研究方向、简介、学院、标签。
- Activity（活动）：id、标题、封面、介绍、类型、时间、地点、人数限制、状态、导师Id、创建者、更新时间。
- ActivityRegistration（报名）：id、活动Id、用户Id、状态（已报名/待审核/已通过/已拒绝/已取消）、报名时间、备注。
- Feedback（反馈）：id、活动Id、用户Id、评分、评价文字、提交时间、审核状态。
- Favorite（收藏）：id、用户Id、活动Id、创建时间。
- Announcement（公告）：id、标题、内容、发布者、发布时间、状态。
- AdminRole（角色/权限）：id、用户Id、角色类型（超级管理员/运营管理员）、权限集合。

## 接口契约（概要清单）
- Auth：注册、登录、刷新令牌、SSO 回调。
- Users：查询/更新个人信息、管理员查询用户列表、禁用/启用。
- Mentors：列表、详情、CRUD。
- Activities：列表、过滤、搜索、详情、CRUD、状态流转、复制。
- Registrations：报名、取消报名、管理员审核、名单导出。
- Feedback：提交反馈、列表、审核。
- Analytics：活动热度、导师人气、参与度统计、报告生成。
- Settings：公告、权限管理。

## 边界与约束
- 初期以 Web 端交互为主；移动端适配基础布局，不含复杂小程序能力。
- SSO 视书院现有系统而定，若无则采用本地账号体系；预留 OAuth2 接入点。
- 导出 Excel 用于线下签到与归档；文件生成与下载需权限校验。
- 评论展示需通过管理员审核；防刷防滥用与基本风控（节流/限速）。

## 验收标准（可测试且量化）
1. 学生可用学号或邮箱成功注册/登录；已登录可编辑个人信息。
2. 活动广场支持导师/类型/时间/状态筛选与关键词搜索；列表/卡片视图渲染正确。
3. 活动详情展示完整信息；在报名时间内可报名/取消；人数限制与重复报名规则生效。
4. “我的活动”含我报名、待参加提醒、历史记录；“我的收藏”可增删并展示。
5. 导师风采包含导师名录与详情，展示过往活动与评价。
6. 活动结束后可推送反馈表；评分与评价可提交；管理员审核后展示。
7. 管理端可创建/编辑/复制活动并进行状态流转；报名名单查看与 Excel 导出可用。
8. 报名审核功能可选开启；支持手动增删学员。
9. 数据分析页可展示活动热度、导师人气、参与度统计并生成报告（基础维度）。
10. 公告管理可在首页展示；权限管理支持不同管理员角色与权限范围。
11. 安全：基于 JWT 的鉴权；管理员接口需权限；基础限流配置；输入合法性校验。
12. 性能：活动列表首屏 2s 内可用；一般筛选与分页接口 500ms 内返回（测试环境）。

## 不确定性与决策
- 后端技术栈：优先采用 Node.js + NestJS；如校方更偏好 Java，可在后续迭代提供 Spring Boot 版本。
- SSO 接入：若书院已有统一认证，采用 OAuth2/OIDC；若无，使用本地账号，预留对接点。
- UI 组件库：Element Plus（学院常用、快速成型）。如后续需要更轻量风格，可评估 Naive UI。
