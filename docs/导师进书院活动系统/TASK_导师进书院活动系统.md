# 导师进书院活动系统 — 原子任务清单

> 依据 DESIGN 文档拆分，每个任务含输入/输出/约束/依赖，便于高成功率交付。

## T1 初始化代码仓与项目结构
- 输入契约：
  - 环境：Node.js ≥ 18；Git；MySQL（开发环境可选）。
  - 决策：后端选 NestJS；前端选 Vue3+Vite；包管理器 npm。
- 输出契约：
  - 目录结构：`frontend/`（Vue3）、`backend/`（NestJS）、`docs/`。
  - README 初始说明、.editorconfig、.gitignore、示例 .env 模板。
- 实现约束：
  - 避免交互式脚手架，采用非交互参数；统一 ESLint/Prettier（若需要）。
- 依赖关系：所有后续任务依赖。

## T2 前端基础脚手架与路由/状态
- 输入契约：
  - `frontend` 初始化完成。
- 输出契约：
  - 路由：学生端与管理端基础路由；Pinia 状态；Element Plus 引入与主题基础配置。
  - 公共布局（导航、页脚）、鉴权路由守卫（占位）。
- 实现约束：
  - 组件按页面模块化；保持简洁一致的代码风格。
- 依赖关系：T1。

## T3 后端基础脚手架与认证模块
- 输入契约：
  - `backend` 初始化完成，NestJS 项目可运行。
- 输出契约：
  - Auth 模块（注册/登录/刷新令牌接口），用户实体与仓储；JWT 策略。
  - 统一错误处理与日志中间件。
- 实现约束：
  - 密钥配置从 `.env` 加载；无敏感信息入库。
- 依赖关系：T1。

## T4 数据库与 ORM 建模（User/Mentor/Activity/Registration/Feedback 等）
- 输入契约：
  - MySQL 可连接的开发环境；后端已引入 ORM（Prisma/TypeORM）。
- 输出契约：
  - 初始数据模型与迁移；基础仓储接口。
- 实现约束：
  - 字段校验与约束（唯一、外键、索引）；避免 N+1 查询；分页。
- 依赖关系：T3。

## T5 活动广场 API 与前端列表/筛选/搜索
- 输入契约：
  - Activities 模块：列表、筛选、搜索、详情接口可用。
- 输出契约：
  - 前端活动列表页与详情页；筛选条件与关键词搜索；分页与加载态。
- 实现约束：
  - 接口 500ms 内响应（测试环境）；参数校验与错误提示友好。
- 依赖关系：T2、T4。

## T6 报名/取消报名与人数限制校验
- 输入契约：
  - Registrations 模块：报名/取消接口；人数限制与重复报名校验。
- 输出契约：
  - 前端详情页报名按钮与状态提示；我的活动（报名/待参加/历史）列表。
- 实现约束：
  - 并发报名一致性保障（数据库约束）；速率限制。
- 依赖关系：T5。

## T7 收藏与导师风采模块
- 输入契约：
  - Favorites 与 Mentors 模块接口。
- 输出契约：
  - 收藏功能（增删与列表）；导师名录与详情页面。
- 实现约束：
  - 列表分页与缓存策略（可选）。
- 依赖关系：T5。

## T8 反馈问卷与评价审核
- 输入契约：
  - Feedback 模块：提交与管理员审核接口。
- 输出契约：
  - 前端反馈表页面；管理员审核界面；审核后在导师详情或活动详情展示评价。
- 实现约束：
  - 防刷与字数限制；基础文本敏感词过滤（可选）。
- 依赖关系：T6。

## T9 管理端仪表盘与活动管理（含复制与状态流转）
- 输入契约：
  - 管理端权限与角色就绪；Activities 管理接口。
- 输出契约：
  - 仪表盘数据卡片；活动创建/编辑表单；复制活动；状态流转（草稿/已发布/报名中/已截止/已结束/已取消）。
- 实现约束：
  - 表单校验与回填；操作审计日志。
- 依赖关系：T5、T6、T8。

## T10 报名名单导出 Excel 与审核流程
- 输入契约：
  - 报名列表接口；审核接口可用。
- 输出契约：
  - 报名名单导出 Excel；审核通过/拒绝流程；手动增删学员。
- 实现约束：
  - 导出权限校验；模板字段一致性。
- 依赖关系：T9。

## T11 数据分析与报告生成
- 输入契约：
  - Analytics 模块：热度、导师人气、参与度统计接口。
- 输出契约：
  - 管理端分析页面与基础报告生成（CSV/Excel/PDF 占位）。
- 实现约束：
  - 统计口径清晰；性能优化（聚合查询与缓存）。
- 依赖关系：T9、T10。

## T12 系统设置（公告管理、权限管理）
- 输入契约：
  - Settings 模块接口。
- 输出契约：
  - 公告发布/列表；角色权限配置页面与生效校验。
- 实现约束：
  - 权限变更审计；最小权限原则。
- 依赖关系：T3、T4。

## T13 安全与稳定性（限流、日志、监控）
- 输入契约：
  - 基础接口就绪。
- 输出契约：
  - 限流配置、统一错误页、结构化日志、关键操作审计、健康检查端点。
- 实现约束：
  - 生产与测试环境隔离；敏感信息不入库。
- 依赖关系：贯穿所有模块，后期联调前完成。

## T14 部署与运维（可选第一版）
- 输入契约：
  - 可运行的前后端与数据库。
- 输出契约：
  - 部署脚本/说明（Windows 环境起步）；后续容器化与 CI/CD 方案草案。
- 实现约束：
  - 环境变量管理（.env）；版本与兼容性检查。
- 依赖关系：整体收尾。
