# 公告功能共识

## 需求描述

- 新增“公告”功能，用于后续发布综测证明、通知附件等内容。
- 第一版包含后台发布管理、前台独立公告页、附件上传与下载。
- 公告附件支持常见文档格式，用户登录后可下载。
- 后台页面需要纳入现有管理后台设计体系。

## 范围

- 前端：前台公告页、公告详情/下载入口、后台公告管理页、导航与路由。
- 后端：公告数据模型、公告 CRUD、附件上传、登录后下载接口。
- 数据库：新增公告表。

## 关键决策

- 展示位置：前台独立页。
- 下载权限：登录后可下载。
- 附件类型：第一版支持常见文档格式（PDF、Word、Excel、压缩包、文本）。
- 管理范围：默认非普通干事可管理公告，普通用户仅浏览与下载。

## 实现约束

- 附件不走现有公开图片上传链路，需使用受控下载接口。
- 保持与现有 Vue 3 + Element Plus + Express + Prisma 架构一致。
- 不引入新依赖，优先复用现有鉴权、管理后台样式与上传基础设施。

## 验收标准

- 后台可新增、编辑、发布/下线公告。
- 公告支持上传一个常见文档附件，并记录原文件名、类型、大小。
- 前台存在独立公告页，可查看已发布公告列表。
- 已登录用户可下载附件，未登录用户会被引导登录。
- 前后端构建/语法检查通过，页面诊断无新增错误。
