# 海报设置功能共识

## 需求与范围

- 在管理员后台新增“海报设置”页面，仅管理员等级为“梦碎怜云”可见与可操作。
- 支持上传图片到后端（/api/admin/upload/image），并将上传后的图片设为“主海报”。
- 设置主海报后，首页海报轮播的第一张应为主海报；清除主海报后恢复原有轮播顺序与兜底逻辑。
- 不改动其他管理员权限与现有活动海报逻辑。

## 验收标准

- 仅“梦碎怜云”在后台菜单中看到“海报设置”入口；其他管理员不可见。
- 在“海报设置”页可以上传图片并设为主海报，预览主海报地址显示正确。
- 首页轮播从后端接口 /api/hero-slides 返回的列表中，主海报位于第一项；清除主海报后，轮播回退到默认逻辑（hero 目录或 logo 背景图）。
- 接口权限控制：只有“梦碎怜云”可以读取与设置主海报；其他管理员访问接口返回 403。

## 技术实现与约束

- 前端：Vue 3、Element Plus、Vite（rolldown-vite@7.1.14）。
- 后端：Node.js、Express、Prisma；端口默认 3001；静态资源 /uploads、/hero、/logo。
- 环境变量：使用现有 JWT_SECRET；图片文件保存至 uploads 目录；主海报配置保存为 uploads/hero-main.json。
- 安全：主海报仅允许使用 /uploads/... 路径的图片，拒绝外链或非本系统文件。

## 不确定性与澄清

- 若后续需要支持多主海报或定时轮换，将另行设计（当前范围仅单一主海报）。
- 现阶段不做图片裁剪/压缩处理，仅限制大小与类型。
