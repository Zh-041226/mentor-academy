## 🚀 快速启动指南

### 开发环境启动
```bash
# 启动后端
cd backend
npm start

# 启动前端 (新终端)
cd frontend  
npm run dev
```

### 访问地址
- 前端页面: http://localhost:3000/
- 后端API: http://localhost:3001/api/

### 测试搜索功能
- 搜索"崇德" - 应返回人工智能讲座

## 🔍 故障排查

### 常见问题
1. **端口占用**: 检查3000/3001端口是否被占用
2. **数据库连接**: 确认MySQL服务运行正常
3. **环境变量**: 检查.env文件配置是否正确
4. **依赖安装**: 运行`npm install`重新安装依赖

### 日志查看
- 后端日志: 终端输出
- 前端日志: 浏览器开发者工具
- 数据库日志: MySQL错误日志
