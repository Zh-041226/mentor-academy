### 🌐 Nginx配置

#### 关键配置项检查
```nginx
# 1. 文件上传大小限制
location /api/ {
    client_max_body_size 10M;  # 必须存在
    proxy_pass http://localhost:3001/;
}

# 2. 上传文件访问路径
location /uploads/ {
    alias /var/www/mentor-academy/backend/uploads/;  # 路径必须正确
}

# 3. 前端静态文件
location / {
    root /var/www/mentor-academy/frontend;  # 确认前端构建文件存在
}
```

## 🚨 常见问题和解决方案

### 问题1: 图片上传失败

**可能原因:**
- uploads目录权限不足
- Nginx文件大小限制
- 磁盘空间不足

**解决方案:**
```bash
# 1. 创建并设置uploads目录权限
mkdir -p /var/www/mentor-academy/backend/uploads
chown -R www-data:www-data /var/www/mentor-academy/backend/uploads
chmod -R 777 /var/www/mentor-academy/backend/uploads

# 2. 检查Nginx配置
nginx -t
systemctl reload nginx

# 3. 检查磁盘空间
df -h
```

### 问题2: API请求失败

**可能原因:**
- 后端服务未启动
- 端口被占用
- 环境变量配置错误

**解决方案:**
```bash
# 1. 检查后端进程
pm2 status
pm2 logs mentor-academy-backend

# 2. 检查端口占用
netstat -tlnp | grep :3001

# 3. 重启后端服务
pm2 restart mentor-academy-backend
```

### 问题3: 前端页面无法访问

**可能原因:**
- 前端构建文件缺失
- Nginx配置错误
- 域名解析问题

**解决方案:**
```bash
# 1. 检查前端构建文件
ls -la /var/www/mentor-academy/frontend/
ls -la /var/www/mentor-academy/frontend/index.html

# 2. 重新构建前端（如果需要）
cd /var/www/mentor-academy/frontend
npm run build

# 3. 检查Nginx配置
nginx -t
systemctl status nginx
```

### 问题4: 数据库连接失败

**可能原因:**
- 数据库服务未启动
- 连接字符串错误
- 数据库用户权限不足

**解决方案:**
```bash
# 1. 检查MySQL服务
systemctl status mysql
systemctl start mysql

# 2. 测试数据库连接
mysql -u mentor_user -p -h localhost academy_mentor

# 3. 检查数据库权限
mysql -u root -p
SHOW GRANTS FOR 'mentor_user'@'localhost';
```

## 🛠️ 一键修复脚本

### 快速修复命令
```bash
#!/bin/bash
# 服务器快速修复脚本

echo "🔧 开始修复服务器问题..."

# 1. 修复目录权限
echo "修复目录权限..."
chown -R www-data:www-data /var/www/mentor-academy
chmod -R 755 /var/www/mentor-academy
chmod -R 777 /var/www/mentor-academy/backend/uploads

# 2. 重启服务
echo "重启服务..."
systemctl reload nginx
pm2 restart all

# 3. 检查服务状态
echo "检查服务状态..."
systemctl status nginx
pm2 status

echo "✅ 修复完成！"
```

## 📞 故障排查流程

### 第一步: 运行诊断脚本
```bash
chmod +x 远程服务器诊断脚本.sh
./远程服务器诊断脚本.sh
```

### 第二步: 根据诊断结果修复
1. **目录权限问题** → 运行权限修复命令
2. **服务未启动** → 重启相关服务
3. **配置文件错误** → 对比并修正配置
4. **资源不足** → 清理磁盘空间或升级服务器

### 第三步: 验证修复结果
1. 重新运行诊断脚本
2. 测试关键功能
3. 检查日志是否有错误
