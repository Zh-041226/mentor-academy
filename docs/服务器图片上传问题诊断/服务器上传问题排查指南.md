# 服务器图片上传问题排查指南

## 🚨 问题现象
服务器部署后，所有图片上传功能都无法正常工作

## 🔍 可能原因分析

### 1. 文件权限问题 (最常见)
**症状**: 上传时返回500错误或权限拒绝
**原因**: uploads目录权限不足，Node.js进程无法写入文件

### 2. 目录不存在
**症状**: 上传时返回文件路径错误
**原因**: /var/www/mentor-academy/backend/uploads 目录不存在

### 3. Nginx配置问题
**症状**: 上传大文件时返回413错误 (Request Entity Too Large)
**原因**: Nginx的client_max_body_size限制过小

### 4. 磁盘空间不足
**症状**: 上传时返回磁盘空间错误
**原因**: 服务器磁盘空间已满

### 5. PM2进程权限问题
**症状**: 应用启动正常但上传失败
**原因**: PM2以错误的用户身份运行，无法访问uploads目录

## 🛠️ 排查步骤

### 步骤1: 检查uploads目录
```bash
# SSH登录服务器后执行
cd /var/www/mentor-academy/backend
ls -la uploads/
```

**期望结果**: 目录存在且权限为755或777
**如果目录不存在**:
```bash
mkdir -p uploads
chmod 755 uploads
chown -R www-data:www-data uploads
```

### 步骤2: 检查目录权限
```bash
# 检查整个项目目录权限
ls -la /var/www/mentor-academy/
ls -la /var/www/mentor-academy/backend/
ls -la /var/www/mentor-academy/backend/uploads/
```

**修复权限**:
```bash
# 设置正确的所有者和权限
chown -R www-data:www-data /var/www/mentor-academy
chmod -R 755 /var/www/mentor-academy
chmod -R 777 /var/www/mentor-academy/backend/uploads
```

### 步骤3: 检查磁盘空间
```bash
df -h
```

**期望结果**: 可用空间 > 1GB
**如果空间不足**: 清理不必要的文件或扩容

### 步骤4: 检查Nginx配置
```bash
# 检查Nginx配置文件
cat /etc/nginx/sites-available/mentor-academy
# 或
cat /etc/nginx/conf.d/mentor-academy.conf
```

**确认包含以下配置**:
```nginx
location /api/ {
    proxy_pass http://localhost:3001/;
    client_max_body_size 10M;  # 确保这行存在
    # ... 其他配置
}
```

**重新加载Nginx**:
```bash
nginx -t  # 测试配置
systemctl reload nginx
```

### 步骤5: 检查PM2进程状态
```bash
pm2 status
pm2 logs mentor-academy-backend
```

**查看错误日志**:
```bash
# 查看最近的错误日志
pm2 logs mentor-academy-backend --lines 50
```

### 步骤6: 测试上传API
```bash
# 创建测试图片
echo "test" > test.txt

# 测试上传接口 (需要先获取管理员token)
```

## 🔧 常见解决方案

### 解决方案1: 权限修复脚本
创建并运行以下脚本:
```bash
#!/bin/bash
# fix-upload-permissions.sh

echo "修复上传目录权限..."
cd /var/www/mentor-academy/backend

# 创建uploads目录（如果不存在）
mkdir -p uploads

# 设置正确的权限
chown -R www-data:www-data /var/www/mentor-academy
chmod -R 755 /var/www/mentor-academy
chmod -R 777 uploads

echo "权限修复完成"
ls -la uploads/
```

### 解决方案2: Nginx配置更新
更新Nginx配置文件，确保包含:
```nginx
server {
    # ... 其他配置
    
    location /api/ {
        proxy_pass http://localhost:3001/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        
        # 关键配置：文件上传大小限制
        client_max_body_size 10M;
        proxy_read_timeout 300;
        proxy_connect_timeout 300;
        proxy_send_timeout 300;
    }
    
    # 上传文件访问
    location /uploads/ {
        alias /var/www/mentor-academy/backend/uploads/;
        expires 1y;
        add_header Cache-Control "public";
    }
}
```

### 解决方案3: PM2重启
```bash
# 重启应用
pm2 restart mentor-academy-backend

# 如果问题持续，完全重新部署
pm2 delete mentor-academy-backend
cd /var/www/mentor-academy
pm2 start ecosystem.config.js
```

### 解决方案4: 环境变量检查
检查后端.env文件:
```bash
cat /var/www/mentor-academy/backend/.env
```

确保包含正确的数据库连接和其他必要配置。

## 🆘 紧急恢复

如果问题严重，可以尝试完全重新部署:
```bash
# 1. 备份数据
cp -r /var/www/mentor-academy/backend/uploads /tmp/uploads-backup

# 2. 重新部署代码
cd /var/www/mentor-academy
git pull origin main

# 3. 重新安装依赖
cd backend
npm install --production

# 4. 恢复uploads目录
cp -r /tmp/uploads-backup/* uploads/

# 5. 修复权限
chown -R www-data:www-data uploads
chmod -R 777 uploads

# 6. 重启服务
pm2 restart mentor-academy-backend
```
