# 首页轮播海报（Hero）

你可以把手机端与电脑端要展示的轮播海报图片放到本文件夹。

使用方法：
- 支持图片格式：JPG、JPEG、PNG、WebP。
- 文件名会按字典序排序（例如 01.jpg, 02.jpg, ...），并在首页轮播中依序展示。
- 放好图片后，无需改代码，前端会自动从后端接口 /api/hero-slides 读取并展示。

尺寸与建议：
- 建议宽高比 16:9 或 3:2，分辨率建议不小于 1920×1080（电脑端），手机端会自动等比裁剪填充。
- 图片体积建议控制在 2MB 以内，以避免加载过慢。

注意：
- 若该文件夹为空或读取异常，系统会回退使用 /logo 文件夹下的示例图片。
